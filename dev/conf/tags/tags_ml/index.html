ML block

This page is generated from the tag definitions in src/conf.

Machine-learned corrections (kernel model); the presence of the block adds the model.

begin ML
    mode = ...
end

Model

mode

Type: String | Default: refit if update = true, else eval

ml training mode (eval=evaluation, refit=retrain from scratch, expand=expand on existing)

model

Type: Bool | Default: true if an ML block is present

whether ML model is used.

sim_params

Type: Float64 | Default: 0.1

similarity parameter for kernel model.

update

Type: Bool | Default: true in a fit (Optimizer and ML blocks), else false

optimization of ML parameters

Parameters

filename

Type: String | Default: ml_params

name of ML parameter file.

init_params

Type: String | Default: zeros

initialization of ML parameters.

Descriptor

apply_distance_distortion

Type: Bool | Default: false

whether distortions (distance only) are considered in descriptor.

apply_distortion

Type: Bool | Default: false

whether distortions are considered in descriptor.

apply_orthogonality

Type: Bool | Default: false

enforce orthogonality of atomic orbitals of different l, m (r=0)

env_scale

Type: Float64 | Default: 1.0

scaling factor for environment features.

key_dims

Type: Vector{Int64} | Default: (empty)

Which descriptor dimensions to be used as descriptor keys. Only use discrete dimensions!

rcut

Type: Float64 | Default: same as rcut of the Options block

ml cutoff radius. Defaults to same as TB.

strc_scale

Type: Float64 | Default: 1.0

scaling factor for structural features.

Data points

ncluster

Type: Int64 | Default: 1

number of cluster used in kmeans clustering.

See also: npoints

npoints

Type: Int64 | Default: 1

number of kernel support points.

See also: ncluster, sampling

sampling

Type: String | Default: random

sampling method for each cluster of descriptors (random, farthest).

Precomputed similarities

sim_mat

Type: Bool | Default: false

precalc similarity matrix of ML descriptors.

See also: sim_tol

sim_tol

Type: Float64 | Default: 0.01

cutoff tolerance for similarity matrix.
