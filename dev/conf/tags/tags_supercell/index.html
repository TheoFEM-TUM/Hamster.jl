Supercell block

This page is generated from the tag definitions in src/conf.

Supercells and trajectories (e.g. MD snapshots); switches a standard run to supercell mode.

begin Supercell
    config_inds = ...
end

Structures

config_inds

Type: String | Default: none (Nconf configurations between Nconfmin and Nconfmax)

configurations to use: a file with configuration indices, or a list of indices.

nbatch

Type: Int64 | Default: 1

number of batches to split the data set.

Nconf

Type: Int64 | Default: 1

number of sample configuration.

Nconf_max

Type: Int64 | Default: 1

maximum configuration index for sample.

Nconf_min

Type: Int64 | Default: 1

minimum configuration index for sample.

poscar

Type: String | Default: SC_POSCAR

path to the POSCAR of the supercell (the reference structure of the trajectory).

See also: xdatcar

val_config_inds

Type: String | Default: none

validation configurations: a file with configuration indices, or a list of indices.

xdatcar

Type: String | Default: XDATCAR

path to the trajectory: a VASP XDATCAR or an HDF5 file with positions (3 × atoms × structures) and optionally lattice (3 × 3 × structures).

See also: poscar, Nconf
