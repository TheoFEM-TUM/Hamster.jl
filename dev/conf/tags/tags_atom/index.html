atom blocks

This page is generated from the tag definitions in src/conf.

Settings per atom species, in blocks begin atom <element> (e.g. begin atom Pb).

begin atom Pb
    alpha = ...
end

Basis

alpha

Type: Float64 | Default: 0.7 × atomic number

decay of the radial functions of the species (effective charge of the hydrogen-like radial functions), which sets how fast the matrix elements fall off with distance.

See also: n

n

Type: Int64 | Default: period of the element

principal quantum number (order of the polynomial) of the radial functions of the species.

See also: alpha

nnaxes

Type: Bool | Default: false

orient the orbital axes along the bonds to the nearest neighbours (the number of neighbours depends on the number of orbitals).

orbitals

Type: Vector{String} | Default: (empty)

orbitals of the species (e.g. s px py pz, sp3dr2 ...); without orbitals, the species does not enter the electronic structure (but its charge enters the Ewald model).

Electrostatics

charge_scale

Type: Float64 | Default: charge_scale of the Ewald block

coupling of the on-site energies of the species to the electrostatic potential.

See also: qeff

qeff

Type: Float64 | Default: 0.0

effective charge of the species for the Ewald model.

See also: charge_scale
