Options block

This page is generated from the tag definitions in src/conf.

General settings of every run.

begin Options
    current_components = ...
end

Input/output

current_components

Type: String | Default: xyz

Which Cartesian components of the current operator to compute and write, any combination of 'x', 'y', 'z' (e.g. "x" or "xz"). Defaults to all three.

See also: write_current

current_file

Type: String | Default: ham.h5

File where current operator is stored.

See also: write_current

h5_deflate

Type: Int64 | Default: 0

Deflate compression level used for HDF5 datasets. Valid values are 0-9, where 0 disables compression, 1 gives the fastest compression, and 9 gives the highest compression effort.

ham_file

Type: String | Default: ham.h5

File where Hamiltonians are stored.

save_vecs

Type: Bool | Default: false

Whether eigenvectors are stored.

verbosity

Type: Int64 | Default: 1

Controls output verbosity (0=minimal, 1=normal, 2=verbose, 3=debug).

write_current

Type: Bool | Default: false

Whether to write current operator.

See also: current_file, current_components, write_hr

write_hk

Type: Bool | Default: false

Whether to write k-space Hamiltonians.

See also: ham_file

write_hr

Type: Bool | Default: true if write_current = true, else false

Whether to write real-space Hamiltonians. Defaults to true if write_current=true.

See also: ham_file

Structure

grid_size

Type: Float64 | Default: same as rcut

size of the grid to divide simulation cell.

poscar

Type: String | Default: POSCAR

path to POSCAR file to define base system.

rcut

Type: Float64 | Default: 7.0

Distance beyond which all interactions are neglected.

See also: rcut_tol, grid_size

rcut_tol

Type: Float64 | Default: 1.0

offset (zero point) of the cutoff function w.r.t. rcut.

Rmax

Type: Int64 | Default: 1

maximum magnitude of translation vectors used for periodic boundaty conditions (default: determined by rcut).

system

Type: String | Default: unknown

name of the system

Basis

interpolate_rllm

Type: Bool | Default: true

force interpolation of rllm.

itp_Ninit

Type: Int64 | Default: 20

number of initial interpolation points.

itp_Nmax

Type: Int64 | Default: 300

maximum number of interpolation points.

itp_tol

Type: Float64 | Default: 1.0e-5

convergence criterion for interpolation.

itp_xmax

Type: Float64 | Default: rcut + |rcut_tol| + 1

maximum x value for interpolation.

itp_xmin

Type: Float64 | Default: 0.0

minimum x value for interpolation.

load_rllm

Type: Bool | Default: false

read rllm data from a file.

See also: rllm_file

onsite

Type: Bool | Default: true

use separate parameters for onsite matrix elements.

rllm_file

Type: String | Default: rllm.dat (rllm.h5 for several systems)

path to the file with the distance dependence of the matrix elements (rllm).

See also: load_rllm

sepNN

Type: Bool | Default: false

use separate parameters for nearest-neighbor interactions (NN1) and the farther shells (NN2). Bonds up to the midpoint between the first two neighbor shells of the reference structure count as nearest neighbors, also when they are distorted. This can improve accuracy, however, may at the same time affect transferability negatively.

tmethod

Type: String | Default: rotation

method for the Slater-Koster transformation matrix (rotation or gramschmidt; the results are the same).

Model

ewald

Type: Bool | Default: true if an Ewald block is present, else false

electrostatic on-site model (also switched on by an Ewald block).

init_params

Type: String | Default: ones

TB parameter initialization (file, ones, zeros, rand).

seed

Type: Int64 | Default: none

seed of the random number generator (plus the MPI rank); without it, runs are not reproducible.

soc

Type: Bool | Default: true if a SOC block is present, else false

spin-orbit coupling model (also switched on by a SOC block).

sp_mode

Type: Bool | Default: true

sparse matrices for Hᴿ and the gradients of fits (not for Hᵏ and the diagonalization, see sp_diag).

See also: sp_diag

sp_tol

Type: Float64 | Default: 1.0e-10

tolerance for value to be considered zero.

tb_model

Type: Bool | Default: true

build TB model.

Diagonalization

diag_method

Type: String | Default: shift-invert

sparse eigensolver when sp_diag=true (shift-invert, krylov-schur).

See also: sp_diag, neig, eig_target

eig_target

Type: Float64 | Default: 0.0

target energy when using sparse eigensolver.

See also: sp_diag, neig

kpoints

Type: String | Default: gamma

file/method for defining k-points (gamma, EIGENVAL, filename.h5).

neig

Type: Int64 | Default: 6

number of eigenvalues when using sparse eigensolver.

See also: sp_diag, eig_target

skip_diag

Type: Bool | Default: false

if true, no eigenvalues are computed.

sp_diag

Type: Bool | Default: false (with skipdiag = true: same as spmode)

sparse Hᵏ and sparse eigensolvers (only some eigenvalues, see diagmethod, neig and eigtarget); not in fits.

See also: diag_method, neig, eig_target

Device and parallelization

device

Type: String | Default: cpu

Compute device for building, diagonalizing and differentiating Hamiltonians (cpu, gpu). gpu requires using CUDA (and using CUDSS for the shift-invert eigensolver); each MPI rank binds to one GPU of its node.

nhamster

Type: Int64 | Default: 1

number of Hamster processes for parallel tasks.

nthreads_bands

Type: Int64 | Default: number of Julia threads

number of tasks working on bands simultaneously.

nthreads_blas

Type: Int64 | Default: 1

number of BLAS threads (diagonalizations with fewer k-points than threads use more).

nthreads_kpoints

Type: Int64 | Default: number of Julia threads

number of tasks working on k-points simultaneously.

Post-processing

dos

Type: Vector{String} | Default: (empty)

post-processing of a standard run: any combination of dos (total DOS), pdos (projected DOS), cohp (crystal orbital Hamilton populations) and jdos (joint DOS, needs nelec), or all (dos, pdos and cohp), e.g. dos = pdos cohp. Results are written to dos.h5; further settings in the DOS block.
