Ewald block

This page is generated from the tag definitions in src/conf.

Electrostatic on-site corrections; the presence of the block (or ewald = true) adds the model.

begin Ewald
    charge_scale = ...
end

Model

charge_scale

Type: Float64 | Default: 1.0

scaling factor for charge values

check_params

Type: Bool | Default: true

take method, rcut, alpha and qeff from the header of the parameter file if they are not set, stop if they differ (false: use the config).

init_params

Type: String | Default: none: the couplings start from charge_scale

parameter file with the Ewald coupling per species (ewald<element> lines, e.g. params.dat of a fit), default: chargescale.

update

Type: Bool | Default: false

fit the Ewald coupling of each species (starting from chargescale or initparams).

Electrostatics

alpha

Type: Float64 | Default: 0: 4 / rcut for method = ewald, 3 / rcut for wolf and zahn

Ewald dampening parameter; 0: 4 / rcut for method = ewald, 3 / rcut for wolf and zahn.

mesh_spacing

Type: Float64 | Default: 0.5

Grid spacing for reciprocal-space PME.

method

Type: String | Default: ewald

method to compute the Ewald sum

rcut

Type: Float64 | Default: same as rcut of the Options block (Wolf, Zahn in a fit: 1.5 × the size of the training cells)

cut-off radius for real-space ewald; Wolf and Zahn: range of the electrostatics (alpha = 3 / rcut), in a fit 1.5 × the size of the training cells if neither rcut nor alpha are set.
