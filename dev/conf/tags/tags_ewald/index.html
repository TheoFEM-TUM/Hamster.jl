Ewald block

This page is generated from the tag definitions in src/conf.

Electrostatic on-site corrections; the presence of the block (or ewald = true) adds the model.

begin Ewald
    charge_scale = ...
end

Model

charge_scale

Type: Float64 | Default: 1.0

scaling factor for charge values

check_params

Type: Bool | Default: true

take method, rcut, alpha and qeff from the header of the parameter file if they are not set, stop if they differ (false: use the config).

init_params

Type: String | Default: none: the couplings start from charge_scale

parameter file with the Ewald coupling per species (ewald<element> lines, e.g. params.dat of a fit), default: chargescale.

update

Type: Bool | Default: false

fit the Ewald coupling of each species (starting from chargescale or initparams).

Electrostatics

alpha

Type: Float64 | Default: 0: 4 / rcut for method = ewald, 3 / rcut for wolf and zahn

Ewald dampening parameter; 0: 4 / rcut for method = ewald, 3 / rcut for wolf and zahn.

centering

Type: String | Default: structure if slab_axis > 0 or cluster, else global

species means subtracted from the potentials: global (the mean of each species over all structures of a run) or structure (the means of each structure, so that the onsite corrections of a structure do not depend on the other structures and a potential offset that differs between structures, e.g. of the slab or cluster terms, drops out).

See also: slab_axis, cluster

charge_compensation

Type: String | Default: surface if slab_axis > 0, else global

where the net effective charge Σq of a structure is compensated: global (uniform background over all atoms, for the slab terms; with cluster, in the whole sum), surface (on the outermost layers of a slab along slab_axis, split so that no average field remains inside), local (on the atoms with missing neighbors of opposite charge, e.g. next to a vacancy, in proportion to the missing neighbors). surface charges enter only the slab terms, local charges also the short-range sum.

See also: slab_axis, cluster

cluster

Type: Bool | Default: false

isolated cluster (e.g. a quantum dot) in a vacuum box: the dipole correction of the full Ewald sum in all directions (vacuum instead of tinfoil boundary conditions; method = ewald, for boxes close to cubic). The net charge of global charge_compensation is a uniform background on the atoms of the cluster.

See also: slab_axis, charge_compensation

mesh_spacing

Type: Float64 | Default: 0.5

Grid spacing for reciprocal-space PME.

method

Type: String | Default: ewald

method of the electrostatic sum: ewald (Ewald/PME), wolf or zahn (case-insensitive).

rcut

Type: Float64 | Default: same as rcut of the Options block (Wolf, Zahn in a fit: 1.5 × the size of the training cells)

cut-off radius for real-space ewald; Wolf and Zahn: range of the electrostatics (alpha = 3 / rcut), in a fit 1.5 × the size of the training cells if neither rcut nor alpha are set.

site_rcut

Type: Float64 | Default: 2.0

search radius (Å) for the bonded neighbour of the site-dependent charges qeff_<element> of the atom blocks; at most rcut of the Options block.

See also: qeff

slab_axis

Type: Int64 | Default: 0

lattice vector (1, 2 or 3) across the vacuum of slab structures; 0: periodic (no slab). With method = wolf or zahn, the plane-averaged long-range part of the electrostatics is added to the potentials (aligned dipoles of successive layers, which the truncated sum misses); with method = ewald, the dipole correction.

slab_scale

Type: Float64 | Default: 1.0

factor of the long-range slab term (slab_axis; plane-averaged potential for wolf and zahn, dipole correction for ewald), e.g. for the screening of the macroscopic field (≈ 1/ε∞), which can differ from the couplings of the short-range part.
