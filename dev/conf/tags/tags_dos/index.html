DOS block

This page is generated from the tag definitions in src/conf.

DOS, PDOS, COHP and JDOS post-processing of a standard run (switched on by the dos tag in Options).

begin DOS
    cohp_pairs = ...
end

Quantities

cohp_pairs

Type: Vector{String} | Default: all coupled pairs

pairs of labels for the COHP, e.g. cohp_pairs = Pb-Br Cs-Br (labels as given by projection). Default (or all): all pairs coupled by an off-site matrix element, including pairs of the same label on different atoms (e.g. Br-Br).

projection

Type: String | Default: element

projection of PDOS and COHP: element (e.g. Pb, Br) or orbital (e.g. Pb-s, Pb-px; spin-summed with SOC).

Method

exact_max_orbitals

Type: Int64 | Default: 4000

largest number of orbitals for which method = auto uses exact diagonalization.

kpm_moments

Type: Int64 | Default: 1024

number of Chebyshev moments of the kpm method (energy resolution ≈ π × bandwidth / 2 / kpm_moments).

kpm_vectors

Type: Int64 | Default: 32

number of random vectors for the stochastic trace of the kpm method.

method

Type: String | Default: auto

method: exact (dense diagonalization at all k-points), kpm (kernel polynomial method, sparse, for large supercells) or auto (exact up to exact_max_orbitals orbitals, kpm above).

Energy grid and broadening

broadening

Type: String | Default: gaussian

broadening of the exact method: gaussian or lorentzian.

emax

Type: Float64 | Default: automatic (see description)

upper end of the energy grid (eV). Default: highest eigenvalue + 5 sigma (exact) or upper spectral bound (kpm).

emin

Type: Float64 | Default: automatic (see description)

lower end of the energy grid (eV). Default: lowest eigenvalue - 5 sigma (exact) or lower spectral bound (kpm).

ne

Type: Int64 | Default: 2000

number of points of the energy grid.

sigma

Type: Float64 | Default: 0.05

broadening width (eV) of the exact method.

Electrons

nelec

Type: Float64 | Default: not set

number of electrons per structure (optional). If set, the Fermi energy, the integrated DOS and the ICOHP are computed.

Output

filename

Type: String | Default: dos.h5

output file of the DOS post-processing.
