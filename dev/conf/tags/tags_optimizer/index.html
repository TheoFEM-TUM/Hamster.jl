Optimizer block

This page is generated from the tag definitions in src/conf.

Parameter fits; the presence of the block switches to an optimization run.

begin Optimizer
    eig_fit = ...
end

Data

eig_fit

Type: Bool | Default: true (false if hr_fit = true)

fit to eigenvalue data (with hr_fit: first to the Hamiltonian, then to the eigenvalues).

See also: hr_fit

hr_fit

Type: Bool | Default: false

switches to fitting the model to Hamiltonian data.

train_data

Type: String | Default: EIGENVAL

path to the training data: a VASP EIGENVAL (pc mode) or an HDF5 file with eigenvalues and kpoints.

See also: train_mode, bandmin

train_mode

Type: String | Default: md with a Supercell block, else pc

type of training data: pc (primitive cell), md (supercells), universal or mixed (not case sensitive).

Parameters

update_tb

Type: Bool | Default: true in a fit

update the TB parameters in a fit: true, false, or a list of parameter indices.

Bands and weights

bandinclude

Type: Vector{Int64} | Default: (empty)

indices of additional bands to be included in the fit.

bandmin

Type: Int64 | Default: 1

lowest band index to include in optimization.

bandmultiplicity

Type: Int64 | Default: 1

Factor used to scale reference-cell band indices, including bandmin and bandinclude, for supercell calculations.

wE

Type: Vector{Float64} | Default: 1 for all bands

weight of each band in the loss; single bands or ranges can be set with wE<band> or wE<first>-<last> (e.g. wE3 = 2, wE10-20 = 0.5).

See also: wk, bandmin

wk

Type: Vector{Float64} | Default: 1 for all k-points

weight of each k-point in the loss; single k-points or ranges can be set with wk<k> or wk<first>-<last> (e.g. wk_1 = 5).

See also: wE

Loss and learning rate

barrier

Type: Float64 | Default: 0.0

parameter magnitude where regularization kicks in.

lambda

Type: Float64 | Default: 0.0

regularization constant

loss

Type: String | Default: MAE

loss function for optimization (MAE, MSE).

lr

Type: Float64 | Default: 0.1

learning rate for gradient descent.

See also: lr_min

lr_min

Type: Float64 | Default: same as lr (no decay)

final learning rate when using learning rate decay if lr≠lr_min.

lreg

Type: Int64 | Default: 2

norm for regularization (1=L1, 2=L2).

See also: lambda, barrier

niter

Type: Int64 | Default: 1

number of gradient descent steps.

Validation

eig_val

Type: Bool | Default: same as eig_fit

validate with eigenvalue data.

val_bandmin

Type: Int64 | Default: same as bandmin

lowest band index to include in validation set.

val_data

Type: String | Default: EIGENVAL

path to the validation data (same formats as train_data).

See also: val_mode

val_mode

Type: String | Default: same as train_mode

type of validation data (pc, md, mixed, multi; not case sensitive).

val_ratio

Type: Float64 | Default: 0.2 if validate = true, else 0

ratio between training and validation set size.

val_weights

Type: Bool | Default: false

if true, same weights are used for training and validation.

valeachiter

Type: Int64 | Default: 1

iteration interval for validation.

validate

Type: Bool | Default: true if valmode or valdata is set

validate the model during the fit (usually set automatically).

Output

printeachbatch

Type: Bool | Default: true if verbosity > 1

profiler prints after each batch.

printeachiter

Type: Int64 | Default: 1

iteration interval for profiler prints.
