Ewald Onsite Correction

An Ewald-based onsite correction is enabled when an Ewald block is present in the configuration file. The correction is only applied if effective charges are defined for all atomic species via the qeff parameter. For periodic systems, the total charge must be neutral, i.e., the sum over all qeff values must be zero.

Overview

The Ewald onsite correction introduces a physically motivated, long-range electrostatic contribution to tight-binding onsite energies.

It accounts for the electrostatic potential generated by all ions in the system and maps it onto onsite Hamiltonian terms.

The correction is of the form:

\[\Delta \varepsilon_i = -\gamma_{s(i)} \, \phi_i\]

where:

  • $\phi_i$ is the electrostatic potential at atomic site $i$ (computed via Ewald, PME, Wolf, or Zahn)
  • $\gamma_{s(i)}$ is a species-dependent coupling parameter
  • $s(i)$ denotes the atomic species of atom $i$

Physical Motivation

In a full electronic structure description, the electrostatic (Hartree) potential contributes to the Hamiltonian as:

\[\hat{H} = \hat{H}_0 - e \, \Phi(\mathbf{r})\]

Projecting onto localized orbitals $\chi_i$ gives:

\[\Delta \varepsilon_i = -e \, \langle \chi_i \mid \Phi(\mathbf{r}) \mid \chi_i \rangle\]

In this model, we approximate:

\[\langle \chi_i \mid \Phi(\mathbf{r}) \mid \chi_i \rangle \approx \Phi(\mathbf{R}_i)\]

which leads to a linear relationship between onsite energy shifts and site potentials.

The parameter $\gamma$ absorbs:

  • orbital averaging effects
  • screening
  • differences between model charges and true charge density

Electrostatic Potential

The potential $\phi_i$ is computed from effective charges $q_i$:

\[\phi_i = \sum_j q_j K(r_{ij})\]

where K(r) is the chosen kernel.

Supported Methods

Ewald / PME (method = "ewald")

  • Exact electrostatics under periodic boundary conditions
  • Includes:
    • real-space contribution
    • reciprocal-space contribution
    • self-interaction correction

Wolf / Zahn (method = "wolf" / "zahn")

  • Approximate, short-ranged electrostatics
  • Uses screened Coulomb kernel:

\[ K(r) = \mathrm{erfc}(α r) / r - \mathrm{shift}\]

  • No reciprocal-space contribution
  • Faster $(O(N))$, but approximate

Damping α and cutoff

With alpha = 0 (default), α is computed from the Ewald rcut:

  • method = ewald: α = 4 / rcut. Here, α only splits the sum into a real- and a reciprocal-space part; the result does not depend on it.
  • method = wolf / zahn: α = 3 / rcut (erfc(3) ≈ 2⋅10⁻⁵ at the cutoff). Here, α is a physical parameter: each charge is screened by a Gaussian charge cloud of radius ≈ 1/α, so potential fluctuations with wavelengths longer than ≈ π/α are suppressed. Smaller α (larger rcut) comes closer to Ewald. The cost grows with rcut³.

For method = ewald, the default rcut is the TB cutoff. For Wolf and Zahn, rcut sets the range of the electrostatics, and α = 3 / rcut follows from it (unless alpha is set, then rcut = 3 / α). In a fit without rcut and alpha, the range follows from the training cells: rcut = 1.5 L, i.e. α = 2 / L, where L is the largest perpendicular width of the training cells (the longest wavelength in them). Wolf then keeps at least 90 % of the potential of every wavelength that occurs in the training data (the fraction 1 - exp(-k²/4α²) at k = 2π/L), while longer wavelengths, which only occur in larger cells and are not tested by the training data, are screened. For 2×2×2 CsPbBr3 (L = 11.87 Å), α = 0.168 1/Å and rcut = 17.8 Å. α and rcut are written to the parameter file at the end of the fit (see below), so that the model uses the same screening in larger cells. Without a fit, rcut or alpha have to come from the parameter file or the config.

Coupling per Species

The coupling $\gamma_s$ is a parameter per species. All species start from charge_scale of the Ewald block, which can be set per species in the atom blocks, e.g. for a hyperparameter search over Pb_charge_scale:

begin Ewald
    charge_scale = 0.6
end

begin atom Pb
    qeff = 1.248
    charge_scale = 0.4      # γ_Pb, the other species use 0.6
end

With update = true in the Ewald block, the couplings are fitted together with the other models, using the gradient $\partial L / \partial \gamma_s = -\sum_{i \in s} \sum_{o \in i} \mathrm{Re}\,(\partial L / \partial H_{R=0})_{oo}\, \phi_i$. The couplings are written to params.dat at the end of a fit, as ewald_<element> lines after the TB and SOC parameters, and read with init_params = params.dat in the Ewald block, which takes precedence over the atom blocks. Without init_params, the ewald_ lines of a parameter file are ignored, so that an explicitly set charge_scale (e.g. in a hyperparameter search) is not overwritten. The effective charges qeff and thus the electrostatic potential (and its neutrality) are not changed by the coupling.

Settings in the Parameter File

At the end of a fit, the settings that define the potentials are written to the header of params.dat, together with the couplings:

begin unknown_system
  rcut = 5.5
  ...
  ewald_method = wolf
  ewald_rcut = 18.0
  ewald_alpha = 0.16666666666666666
  ewald_qeff_Br = -0.756
  ewald_qeff_Cs = 1.02
  ewald_qeff_Pb = 1.248
end

When a model is built from this file (init_params of the Ewald block, otherwise init_params), settings that are not set in the config are taken from the header, so that a fitted model is used with the settings it was fitted with, e.g., in larger cells. The adopted settings are printed and appear in the model summary. If a setting is set in the config and differs from the header, Hamster stops with an error, since the fitted couplings belong to the settings of the file. To change them deliberately (e.g., to refit with a different α), set check_params = false in the Ewald block. For method = ewald, rcut and alpha only affect the numerics and are not taken from the file; method and qeff are.

Mean Centering

The electrostatic potential is only defined up to a constant.

To ensure consistency with onsite fitting, we subtract a per-species mean:

\[\phi_i \rightarrow \phi_i - \langle \phi \rangle _ {s(i)}\]

This ensures:

  • no arbitrary offset in onsite energies
  • compatibility across different structures

Model Summary

When the model is built in a Hamster run, a summary is appended to hamster.out (one block per model, e.g. for the training and the validation set). Settings from the config file are not repeated:

================================================================================
  Ewald Model Summary (training set)
--------------------------------------------------------------------------------
      structures:                  6
      method, rcut:                ewald, 5.50 Å
      alpha:                       0.7273 1/Å (4 / rcut)
      subtracted species mean φ̄:   Br 4.7532 V, Pb -8.1202 V

  Onsite corrections Δε = -γ (φ - φ̄) per species (meV):
    species sites      σ    min     p1    p99    max  max/σ  >3σ % σ_strc    δφ̄
    Br        144  193.8 -459.9 -398.3  409.8  520.1   2.68   0.00    5.3    2.2
    Pb         48  143.1 -319.6 -296.8  299.4  347.0   2.43   0.00    6.2    2.5

    φ̄: species mean of the site potentials over all structures of this run.
    σ: width of Δε; max/σ: largest |Δε| relative to σ; >3σ %: fraction of
      sites with |Δε| > 3σ.
    σ_strc: spread of the per-structure species means, i.e. the part of Δε
      that is lost if the model is built for a single structure.
    δφ̄: uncertainty of φ̄ in meV of Δε, σ_strc / √(number of structures)
      (single structure: σ / √sites). The onsite corrections shift by about
      δφ̄ if other structures are computed together.
================================================================================
  • φ̄ is the species mean that is subtracted (see Mean Centering). It is taken over the structures of the current run, so it can differ between training, validation and later runs.
  • σ, min, max and the 1% / 99% percentiles describe the distribution of the corrections. max/σ and >3σ % show how pronounced the tails are, which is useful to compare large cells with the training cells.
  • σ_strc is the spread of the per-structure species means. This part of the correction is lost if the model is built for a single structure.
  • δφ̄ is the uncertainty of φ̄: the corrections of a structure shift by about this amount if it is computed together with other structures. If it exceeds 10 meV for a species, the summary ends with a warning (also printed to the log). It decreases with the number of structures in the run and with the cell size: e.g., for 2x2x2 CsPbBr3 cells (Wolf) 10 meV with 10 structures, 3 meV with 100 (the band gaps of the two runs differ by about 3 meV) and 30-50 meV for a single structure, while the estimate for a single 16x16x16 cell is 1-2 meV.

Real-Space Neighbor Grid

The real-space Ewald sum reuses the neighbor grid and translation vectors of the structure, which cover pairs up to the TB cutoff rcut and the grid_size. If the Ewald rcut is larger, both are rebuilt for the Ewald cutoff, and the model summary states real-space neighbor grid: rebuilt.
